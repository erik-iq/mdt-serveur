UEFI x64

Installation depuis zéro

  1. Préparer le serveur

    IP fixe, stockage dédié, Python 3.12 pour tous les utilisateurs, ADK et module complémentaire WinPE.

  2. Installer WDS

    Exécutez scripts/Install-Wds.ps1. Les réponses PXE restent désactivées par défaut.

  3. Créer l’image de démarrage

    Exécutez scripts/Build-WinPE.ps1 avec l’URL HTTPS de la console et importez l’image dans WDS.

  4. Valider un poste de laboratoire

    Configurez le relais DHCP si nécessaire, activez les réponses WDS, démarrez en UEFI et lancez un déploiement supervisé.

Le réseau décide du démarrage.

Ne définissez pas systématiquement les options DHCP 66/67. Sur plusieurs VLAN, utilisez les relais DHCP vers DHCP et WDS. Consultez docs/INSTALLATION.md.

Ce que la console confirme

« Image appliquée » signifie que DISM et le démarrage UEFI ont été préparés. Le premier démarrage Windows, les pilotes, l’activation et l’OOBE doivent ensuite être contrôlés sur le poste.

Autorisation WinPE

Saisissez le code d’installation dans l’assistant PXE du poste. Le code est réservé à sa MAC, valable deux heures et désactivé au début de l’installation.

Accès au lanceur texte

Munissez-vous du chemin WIM sur un partage SMB accessible depuis WinPE. Une confirmation d’effacement sera demandée sur le poste.
