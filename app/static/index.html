MISES À JOUR DES POSTES

Correctifs Windows

Les KB du serveur .250 sont installées en premier, puis HPIA si sélectionné, les logiciels et le dossier IQ. Le suivi apparaît dès la première connexion Windows.

Dépôt de correctifs sur .250

Mode d’emploi des correctifs

Windows Update et Microsoft Store restent manuels. La préparation installe les KB compatibles depuis le cache .250, sans recherche Windows Update sur le poste. Le cache KB ci-dessous est facultatif et reste disponible pour les anciens déploiements.

La veille des versions Windows est quotidienne à 02:00. Le bouton de téléchargement permet de préparer séparément le cache KB ; les KB compatibles de ce cache sont installées au début de la préparation.

Nouvelles versions de Windows 11

Veille quotidienne Microsoft. Une nouvelle version reste à préparer et à tester avant son passage en production.

Comment préparer une nouvelle version ?
  1. Récupérer le média français depuis Microsoft avec une licence adaptée.
  2. Ajouter son image dans Atelier et préparer les éditions Famille et Pro avec les réglages français suisse.
  3. Tester les pilotes, HPIA, les logiciels, les KB et les redémarrages sur un poste.
  4. Après validation, sélectionner les nouveaux profils pour les déploiements de production. Conserver les anciens profils pour revenir en arrière.

La veille ne télécharge pas automatiquement un ISO et ne met à niveau aucun poste. Un changement de version n’est pas une KB cumulative. La disponibilité chez Microsoft ne confirme pas la compatibilité du matériel.
